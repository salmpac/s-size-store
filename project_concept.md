Метрики (решено, подробности в docs/analytics.md):
Пишем не счетчики, а поток событий в таблицу events, цифры считаем запросами по нему.
Воронка: impression -> card_click -> outbound -> purchase.
Пользователь опознается по cookie aid (устройство, год) + sid (сессия, 30 мин). Логина нет.
Ссылка на товар всегда идет через наш редирект /r/{item_id}?p={позиция} -> 302 на партнера.
Так мы видим 100% переходов и меняем партнерку одной строкой в таблице partners, не трогая каталог.
В партнерскую ссылку подставляем subid = одноразовый click-токен (не anon_id, чтобы не светить юзера).
Партнерка потом присылает постбэк по этому токену - так воронка замыкается до реальных денег.
Позицию в выдаче логируем обязательно, иначе не отличить хорошую вещь от той, что просто была сверху.
Impression'ы шлет фронт батчами через sendBeacon, все события пишутся в БД пачкой раз в секунду.
Сырые события храним 90 дней, дальше только суточные агрегаты.
Плюс ставим Яндекс Метрику (бесплатная): своя аналитика отвечает "что работает", Метрика - "почему не работает" (вебвизор, карта кликов). Решения по деньгам принимаем только по своим данным.
Дашборд не строим, будет страница /admin/stats с несколькими готовыми запросами.

Монетизация в МВП: без paywall, бесплатно + реферальные ссылки. Телеграм-бот с оплатой из МВП выпадает.
